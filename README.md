# Collection

Данный проект был сделан для оттачивания навыков по проектированию рест сервиса.
К данному проекту не предусмотрено написание тестов.
Данный проект более не будет обновляться.

Дальнейшие темы по проектам - брокеры, прокси, grpc, асинхронное взаимодествие между сервисами и более глобальные и более интересные проекты.
